# Hi Admin — bản phát hành

Repo này chỉ chứa **file cài đặt Hi Admin** (Windows) để các máy tải về và tự cập nhật (electron-updater).
Không có mã nguồn. Mã nguồn nằm ở repo riêng tư `top10sv/hi-admin`.

- Mỗi bản phát hành có: bộ cài `.exe`, `latest.yml` (để app tự kiểm bản mới) và tệp `.blockmap`.
- Bản phát hành được tạo tự động từ workflow `release.yml` của repo nguồn (đăng **nháp**, chủ dự án duyệt rồi mới công khai).
- Không đặt khoá, mật khẩu, cấu hình kết nối hay dữ liệu website vào repo này.
